The scope

What I can help with

We agree on the deliverables, review rounds, and handoff before work begins.

Responsive frontend implementation

Layouts and components that adapt to different screens, with clear navigation and predictable interactions.

Useful interface behaviour

Forms, menus, filtering, and other agreed interactions, including relevant loading, empty, validation, and error states.

Technical search foundations

Semantic HTML, page titles, descriptions, canonical URLs, internal links, and sitemap support where appropriate to the site.

Testing and handoff

Checks of key user journeys, keyboard access, mobile layouts, and essential loading behaviour, followed by a documented handoff.

The process

How we’ll work together

  1. Define the build

    We review the designs, content, hosting, integrations, and who will maintain the site, then agree on an appropriate implementation.

  2. Develop and review

    The site is built in reviewable stages so layout, content, and interaction decisions can be checked before launch.

  3. Validate and launch

    We test the agreed paths, resolve launch issues, and confirm deployment access, ownership, and the maintenance arrangement.

What to include in your brief

Send the designs or existing site, page list, content, required interactions, hosting preferences, and any integration requirements. Payments, user accounts, databases, and ongoing maintenance are scoped explicitly.

Before we begin

Your questions, answered.

Can you build from an existing Figma design?

Yes. I review the design files, responsive layouts, component states, and functionality before estimating the implementation.

Can you handle both web design and development?

Yes. A combined project covers the website structure, visual design, frontend implementation, and the agreed launch checks. Each phase has a clear review point.

Are hosting, backend systems, and maintenance included?

Those responsibilities are defined in the proposal. A frontend build does not automatically include hosting fees, custom backend services, payment integrations, or ongoing maintenance.

Can you guarantee a Google ranking after launch?

No. Technical SEO makes a site easier to crawl and understand, but rankings also depend on content, competition, authority, location, and search engine decisions.
